<h2>React Food (Ongoing Project):</h2>
<ul>
  <li>
      Developed with an optimized MVC architecture to build a scalable and maintainable food app where users can pick their food items, add them to the cart, and proceed to checkout. This architecture ensures clear separation of concerns, making the application more organized and easier to manage.  
  </li>
  <li>
    Utilized React custom hooks for efficient management of multiple backend API calls and designed a custom modal box to enhance user interaction. The modal box is used for displaying cart items, managing the checkout process, and handling errors, creating a seamless and intuitive user experience.
  </li>
  <li>
    Built a robust backend using an Express server, with MongoDB and Mongoose for efficient data storage and modeling. Additionally, implemented fs for handling images, ensuring smooth and secure image processing within the application.
  </li>
  <li>
    Upcoming features include the integration of two-way verification using JWT for enhanced security and the implementation of a system to send personalized confirmation emails with detailed order information after a successful purchase, along with more enhancements planned to further elevate the user experience and application functionality.
  </li>
  <li>
    Access the deployed application from here : https://food-order-app-eta-sand.vercel.app/
  </li>
  <li>
    Access the backend repository : https://github.com/raghavtonk/food-order-app-backend
  </li>
</ul>
